Install from file

Signing with a tracked repo's key installs the .zip as that repo's extension, with the same ID and data.

Kept keys

Keys of .zip files installed without a repository. Forgetting a key deletes it: a .zip signed for that extension later installs as a different extension, without its data.

    GitHub token

    Raises the API limit from 60 to 5000 requests per hour. Kept in this browser and sent only to api.github.com. A fine-grained token with no permissions is enough for public repos.

    Backup

    The export file contains the signing keys of your .zip-based extensions. Keep it private. Without these keys a reinstall gets a new extension ID and loses its data.
